# Описание

Небольшое тестовое задание по описанию архитектуры симулятора РЛС.

Оформлено как смесь C4 и arc42 подходов, чтобы структурировать декомпозицию (С4), но при этом оставь достаточно текстового описания для реализации (arc42)

Целевой стек - Rust + TypeScript.

## Вспомогательные скрипты

check.py - проверка (и возможная замена, если в индексах ххх) индексов SWRS требований.

## Известные недоработки и ошибки

В диаграмме состояний приложения не все переходы отображены.
Нет даже рамочного описания кодов ошибок API.
Не проработаны структуры данных (например для БД или передаваемых по API).
