===== С1.6.2 Подмодуль настроек

[[SWRS-056-modsim-smodset-generic]]
.SWRS-056-modsim-smodset-generic
--
:srs-upstream: BRS33200-controllist, BRS33210-controlsettings
include::snippets.adoc[tag=srs-attribs]
Подмодуль настроек должен предоставлять кнопку вызова меню настроек симуляции.

--

[[SWRS-057-modsim-smodset-basis]]
.SWRS-057-modsim-smodset-basis
--
:srs-upstream: BRS33200-controllist, BRS33210-controlsettings
include::snippets.adoc[tag=srs-attribs]
При нажатии на кнопку вызова меню настроек симуляции подмодуль настроек должен отобразить окно со списком настроек симуляции.

--

Список настроек включает в себя настройки для подмодулей:

* С1.5.2 Подмодуль колец
* С1.5.3 Подмодуль зон
* С1.5.5 Подмодуль управления
* С1.5.4 Подмодуль объектов
* С1.6.1 Подмодуль генерации объектов

===== С1.6.3 Подмодуль управления


[[SWRS-058-modsim-smodctrl-generic]]
.SWRS-058-modsim-smodctrl-generic
--
:srs-upstream: BRS33200-controllist, BRS33230-controlpause
include::snippets.adoc[tag=srs-attribs]
Подмодуль управления должен предоставлять панель паузы с взаимно исключаемыми (не могут быть доступны одновременно) кнопками "Пауза" и "Продолжить".

--

[[SWRS-059-modsim-smodctrl-pause]]
.SWRS-059-modsim-smodctrl-pause
--
:srs-upstream: BRS33230-controlpause
include::snippets.adoc[tag=srs-attribs]
Подмодуль управления должен предоставлять панель паузы с кнопкой "Пауза" для приостановки симуляции.

--

[[SWRS-060-modsim-smodctrl-resume]]
.SWRS-060-modsim-smodctrl-resume
--
:srs-upstream: BRS33230-controlpause
include::snippets.adoc[tag=srs-attribs]
Подмодуль управления должен предоставлять панель паузы с кнопкой "Продолжить" для возобновления симуляции.

--
