
NOTE: ПМГО - подмодуль генерации объектов

[[SWRS-047-modsim-smodgen-startup]]
.SWRS-047-modsim-smodgen-startup
--
:srs-upstream: BRS33000-trainingmode, BRS33141-objstartup
include::snippets.adoc[tag=srs-attribs]
ПМГО должен после заупска режима тренировки сгенерировать объекты в произвольном количестве, но не не более лимита (SWRS-034-modmap-smodobj-settings-limits).

--

[[SWRS-048-modsim-smodgen-types]]
.SWRS-048-modsim-smodgen-types
--
:srs-upstream: BRS33144-objtypes
include::snippets.adoc[tag=srs-attribs]
ПМГО должен предоставлять возможность генерировать объекты двух типов: БВС и птица.

--

Алгоритмы генерации и изменения параметров объектов, согласно их типах, определены в BRS33144-objtypes.

Параметры объектов:

* тип
* позиция
* скорость
* направление
* время "жизни"
* статус взаимодействия

[[SWRS-049-modsim-smodgen-process1]]
.SWRS-049-modsim-smodgen-process1
--
include::snippets.adoc[tag=srs-attribs]
ПМГО должен с постоянной цикличностью обновлять параметры объектов, согласно их типам,  включая:

* изменение параметров
* удаление объекта согласно алгоритму
* произвольное удаление объекта
* произвольная генерация новых объектов, если не достигнут предел (SWRS-034-modmap-smodobj-settings-limits)

--
