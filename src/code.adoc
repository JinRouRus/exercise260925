=== База данных

[[SWRS-xxx-db-accounts]]
.SWRS-xxx-db-accounts
--
:srs-upstream: SRS-006-cont-db-data
include::snippets.adoc[tag=srs-attribs]
База данных должна содержать таблицу аккаунтов ПО со следующими полями:

* id_account [unique, key]
* login
* hash_pwd
* role
* details_json

--

Поле "role" может принимать два значения:

* regular - для пользователей без привилегий администратора.
* admin - для пользователей с привилегиями администратора.

Поле "details_json" содержит детализированную информацию о пользователе.

=== IPC контракты

Данный раздел описывает контракты между C1a Frontend (TypeScript) и C1b Backend (Rust)

==== Команды

[cols = "1,10,8,4"]
|===

| # |  Сигнатура | Описание | Модули

| 1 | login(login: String, password: String) -> Result<(),error>
| Попытка авторизации
| С1.1 Модуль авторизации

| 2 | request_training_settings(source: String) -> Result<training_settings: String,error>
| Нажатие кнопки "Тренировка" из главного меню +
Вызов меню настройки симуляции в процессе тренировки
| С1.7 Модуль главного меню +
С1.6 Модуль симуляции

| 3 | mm_profile() -> Result<accountinfo_history: String,error>
| Нажатие кнопки "Профиль" из главного меню
| С1.7 Модуль главного меню

| 4 | mm_settings() -> Result<settings_accounts: String,error>
| Нажатие кнопки "Настройки" из главного меню
| С1.7 Модуль главного меню

| 5 | profile_pwd(password: String) -> Result<(),error>
| Смена пароля
| С1.2 Модуль профиля

| 6 | profile_history(id: u32) -> Result<training_stat: String,error>
| Просмотр статистики тренировки +
Просмотр результат тренировки
| С1.2 Модуль профиля +
С1.6 Модуль симуляции

| 7 | profile_exit() -> Result<(),error>
| Выход из профиля
| С1.2 Модуль профиля

| 8 | settings_basic(data_json: String) -> Result<(),error>
| Обновление настроек ПО
| С1.3 Модуль настроек

| 9 | settings_account(data_json: String) -> Result<(),error>
| Операция с аккаунтами (CRUD)
| С1.3 Модуль настроек

| 10 | training_settings(data_json: String) -> Result<(),error>
| Обновление настроек симуляции
| С1.7 Модуль главного меню

| 11 | request_notifications() -> Result<notifications: String,error>
| Вызов меню центра уведомлений
| С1.6 Модуль симуляции

| 12 | simulation_pause() -> Result<(),error>
| Нажатие кнопки "Пауза"
| С1.6 Модуль симуляции

| 13 | simulation_resume() -> Result<(),error>
| Нажатие кнопки "Продолжить"
| С1.6 Модуль симуляции

| 14 | object_dbl(id: u32) -> Result<(),error>
| Двойное нажатие на объект
| С1.6 Модуль карты

|===
