=== База данных

[[SWRS-xxx-db-accounts]]
.SWRS-xxx-db-accounts
--
:srs-upstream: SRS-006-cont-db-data
include::snippets.adoc[tag=srs-attribs]
База данных должна содержать таблицу аккаунтов ПО со следующими полями:

* id_account [unique, key]
* login
* hash_pwd
* role
* details_json

--

Поле "role" может принимать два значения:

* regular - для пользователей без привилегий администратора.
* admin - для пользователей с привилегиями администратора.

Поле "details_json" содержит детализированную информацию о пользователе.
