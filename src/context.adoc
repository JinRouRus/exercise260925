=== Бизнес контекст

По является симулятором взаимодействия с данными РЛС и обнаруженными симулированными объектами.

.Бизнес контекст ПО
image::../out/src/diags/bcontext.png[]

ПО подразумевает только взаимодействие с пользователем. С другими (под-)системами взаимодействия не предусматривается.

=== Технический контекст

.Технический контекст ПО
image::../out/src/diags/tcontext.png[]

Взаимодействие с ПО должно быть реализовано посредствам клавиатуры и мыши.

ПО должно быть реализовано в виде десктопного приложения для работы на ПК под ОС Windows.
