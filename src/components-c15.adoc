[[SWRS-037-modmap-smodobj-objattr]]
.SWRS-037-modmap-smodobj-objattr
--
:srs-upstream: BRS33145-objattr
include::snippets.adoc[tag=srs-attribs]
При наведении курсора мыши на объект, подмодуль объектов должен отображать следующую информацию об объекте:

* скорость движения
* долгота
* широта

--

На основании ADR-004-objects-colors. Подмодуль объектов с помощью цвета отображают статус объекта:

* серый - объект, с которым пользователь не взаимодействовал
* синий - объект, с которым пользователь взаимодействовал
* зеленый - объект, с которым пользователь взаимодействовал и который модулем симуляции (С1.6) подтвержен как БВС
* красный - объект, с которым пользователь взаимодействовал и который модулем симуляции (С1.6) не подтвержен как БВС
